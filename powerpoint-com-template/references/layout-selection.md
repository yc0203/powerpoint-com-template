# 单模板选页指南

先读已选模板的预览和样式档案。每页先定一句核心结论和信息之间的关系，再选同一套模板里合适的页型和原生组件。

| 信息关系 | 版式选择 |
|---|---|
| 同标准并列比较 | 双栏对照或行列矩阵，证据图对齐尺度 |
| 一张总览引出两组证据 | 左右分区，证据侧上下排，图注贴图 |
| 多步、有分支或汇合 | 可编辑流程图，主路径有箭头，同级分支并列 |
| 用时间说明安排 | 有具体工期用甘特，只讲阶段用时间条或步骤模板 |
| 风险与应对 | 问题和措施逐条对应，确有四类时再用四格 |

没有现成页型时，用 COM 按同一套模板的版心、组件、配色、字号和留白建立新分区。目录、图文、流程和计划可以采用不同布局，保持同套模板的风格。导出 PNG，对照所选模板的对应页型复核；原稿的示例数字、人物和品牌不带进新稿。
